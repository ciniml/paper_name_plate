PaperPlate Sender BLE でネームプレートの公開内容と画像を設定

1. 公開内容（NFC で配布・画面に表示）

全画面画像を送ってあると画面は画像で覆われ、テキストは NFC でだけ配布されます。「表示画像を消す」でテキスト表示に戻ります。スマホをかざすと URL が開き、テキストレコードに名前・メール・GitHub・X・メモが入ります。GitHub と X はアカウント名のみ（@ 不要）。名前〜メモの 5 項目は合計 240 バイトまで（日本語は 1 文字 3 バイト）。

2. 画像

プレビューが実際の表示（黒 = インク）です。画面が狭いと縮小表示されるため、細部は実機で確認してください。

3. 状態

Android の Chrome で開いてください。ボタンを押すとデバイス選択が出ます。
